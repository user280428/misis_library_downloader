# Что делает программа

Программа *misis_library_downloader* скачивает ту или иную публикацию с сайта [**Электронной библиотеки мисис**](https://lib.msk.misis.ru/elib/m_main.php)

в формате PDF

Программа не собирает данные пользователя
___

# Как установить
- Перейдите в раздел [**Releases**](https://github.com/user280428/misis_library_downloader/releases) в правой части экрана
- Нажмите на файл [**misis_library_downloader.exe**](https://github.com/user280428/misis_library_downloader/releases/download/v0.1/misis_library_downloader.exe) и установите его в нужную вам папку
___

# Как пользоваться
1. Откройте программу, вы увидите предупреждение антивируса, нажмите **Подробнее**, затем **Выполнить в любом случае**


2. Перед вами откроется окно программы, в нем нужно заполнить следующие данные
   - Номер студенческого билета (обычно это семизначное число)
   - Ваше полное имя с большой буквы
   - Ссылку на публикацию - можно вставить комбинацией клавищ Ctrl + V
   (предварительно найдите эту публикацию на сайте библиотеки)
   - Будущее название файла - **<u>название файла</u>**


3. Нажмите на на кнопку **Скачать**
   - В окне программы появится счетчик скачанных страниц, он начинается с -1, это нормально
   - Счетчик страниц будет увеличиваться
   - По окончании загрузки в поле счетчика появится **Скачивание завершено, файл сохранен - <u>название файла</u>**


4. В папке рядом с программой появится файл **<u>название файла</u>** - это и есть скаченная публикация
